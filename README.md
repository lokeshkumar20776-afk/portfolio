# Alex Morgan | Portfolio

A responsive HTML, CSS and JavaScript website created for the Web Development subject activity.

## Run locally
1. Download or clone this project folder.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Internet is needed for the Google Fonts and remote Unsplash images.

## Deploy
Upload this folder's contents to a GitHub repository, then enable **Settings → Pages → Deploy from a branch → main → /(root)**.
